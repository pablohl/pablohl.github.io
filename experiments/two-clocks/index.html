Waiting moves the decision too.

Evidence may change what you should do, but it cannot return spent time or budget. An unfavorable outcome does not, by itself, make the earlier choice unjustified.

The useful question is whether another test could change your action while that action is still available.

How this illustrative model works

There are 12 weeks and $100,000. Building costs $60,000, takes 8 weeks, and returns $180,000 if execution succeeds. A preliminary test costs $5,000 and one week. The starting chance that the underlying idea is viable is 50%.

A clearer test gives a supportive signal 80% of the time when the idea is viable, and 20% when it is not. Results update the viability estimate using Bayes’ rule; they do not change the hidden project. Execution succeeds 90% of the time for a viable idea and 10% otherwise. Optional settings change these assumptions for a replay.

The result of each test is randomly sampled from the hidden project. The same-project replay preserves that project and its draws. Expected values count future choices; realized net subtracts all incurred test and build costs. All amounts and probabilities are invented for this explanation, not forecasts or recommendations.
